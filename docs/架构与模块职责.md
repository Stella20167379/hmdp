# HMDP-Plus 架构与模块职责

## 1. 前后端分离与多模块架构

### 前端应用

- 位于 `hmdp-vue3/`，是独立的 Vue 3 + Vite 前端工程。
- 通过 Axios 调用 Spring Boot 后端接口，开发环境由 Vite 将 `/api` 请求代理到 `http://localhost:8085`。
- 负责登录注册、商铺浏览、博客互动、用户资料、优惠券秒杀与订阅等页面交互。
- 使用 Vue Router 管理页面路由，使用 Pinia 管理用户令牌等前端状态，可独立构建和部署为静态资源。

### 后端服务

- 后端采用 Maven 聚合工程，根目录 `pom.xml` 统一管理 Java 17、Spring Boot 3.5.4 和各子模块版本。
- `hmdp-core-service/` 是可运行的 Spring Boot 核心服务，提供 REST 接口并编排业务流程。
- `hmdp-common/`、`hmdp-parameter/`、`hmdp-redis-tool-framework/`、`hmdp-redisson-framework/`、`hmdp-mq-framework/`、`hmdp-id-generator-framework/` 和 `hmdp-sharding/` 提供公共模型与可复用基础能力。
- 核心业务采用 Controller -> Service -> Mapper -> ShardingSphere -> MySQL 的分层调用结构，并通过 Redis、Redisson、Kafka 和 Lua 支撑缓存、限流、锁、幂等与异步下单。

## 3. 后端模块结构

### 3.1 聚合工程与核心服务

| 路径 | 模块职责 |
| --- | --- |
| `pom.xml` | Maven 父工程，聚合后端模块并统一依赖、版本和构建插件。 |
| `hmdp-core-service` | 可运行的核心业务服务，承载 HTTP 接口、业务实现、持久化、缓存编排、消息生产消费和数据一致性任务。 |
| `hmdp-common` | 提供公共常量、业务枚举、基础异常、日期工具、Spring 上下文与环境辅助能力。 |
| `hmdp-parameter` | 提供优惠券、订单、订阅等跨层请求 DTO 和响应 VO。 |
| `hmdp-sharding` | 引入 ShardingSphere-JDBC 分库分表能力及兼容支持；具体数据源和路由规则由核心服务配置。 |

### 3.2 Redis 与 Redisson 基础框架

| 路径 | 模块职责 |
| --- | --- |
| `hmdp-redis-tool-framework/hmdp-redis-common-framework` | 自动配置 RedisTemplate 等 Redis 基础访问能力。 |
| `hmdp-redis-tool-framework/hmdp-redis-framework` | 封装 Redis Key、缓存读写、集合操作和统一缓存接口。 |
| `hmdp-redis-tool-framework/hmdp-redis-rate-limit-framework` | 提供秒杀访问令牌、滑动窗口与令牌桶限流，以及指标和处罚扩展点。 |
| `hmdp-redisson-framework/hmdp-redisson-service-framework/hmdp-redisson-common-framework` | 提供 Redisson 客户端基础配置、锁参数解析和本地锁信息缓存。 |
| `hmdp-redisson-framework/hmdp-redisson-service-framework/hmdp-service-lock-framework` | 提供注解式分布式读锁、写锁、公平锁和可重入锁。 |
| `hmdp-redisson-framework/hmdp-redisson-service-framework/hmdp-repeat-execute-limit-framework` | 通过注解与切面限制重复执行，用于接口或消息消费幂等。 |
| `hmdp-redisson-framework/hmdp-redisson-service-framework/hmdp-bloom-filter-framework` | 提供可配置布隆过滤器及处理器工厂，拦截不存在的热点查询。 |
| `hmdp-redisson-framework/hmdp-service-delay-queue-framework` | 封装 Redisson 延迟队列的生产、消费、隔离区域和启动初始化。 |

### 3.3 消息与分布式 ID 框架

| 路径 | 模块职责 |
| --- | --- |
| `hmdp-mq-framework/hmdp-mq-common-framework` | 定义统一消息扩展模型。 |
| `hmdp-mq-framework/hmdp-mq-producer-framework` | 封装 Kafka 消息发送及发送成功、失败回调模板。 |
| `hmdp-mq-framework/hmdp-mq-consumer-framework` | 封装 Kafka 消息反序列化、消费前后处理和异常处理模板。 |
| `hmdp-id-generator-framework` | 基于 Snowflake 生成全局 ID，并通过 Redis Lua 分配 workerId 与 dataCenterId。 |

## 4. 核心服务分包结构

### 4.1 应用入口与 Web 层

| 包路径 | 模块职责 |
| --- | --- |
| `org.javaup.HmDianPingApplication` | Spring Boot 应用启动入口，并启用事务管理。 |

| `org.javaup.config` | 配置 MVC 拦截器、JSON 序列化、统一异常响应及核心 Bean。 |
| `org.javaup.dto` | 定义登录、用户、滚动分页和统一响应结果等核心服务内部 DTO。 |
| `org.javaup.utils` | 提供登录态、令牌刷新、缓存、正则、密码、ID 与通用常量等辅助能力。 |

### 4.2 业务与数据访问层

| 包路径 | 模块职责 |
| --- | --- |
| `org.javaup.service` | 定义用户、商铺、博客、关注、优惠券、订单、对账和通知等业务接口。 |
| `org.javaup.service.impl` | 实现业务规则，协调缓存、分布式锁、消息队列、Mapper 与补偿流程。 |
| `org.javaup.mapper` | 定义 MyBatis-Plus Mapper，访问用户、商铺、博客、优惠券、订单及对账数据。 |
| `org.javaup.entity` | 定义用户、商铺、博客、优惠券、订单、路由与对账日志等持久化实体。 |
| `org.javaup.model` | 定义秒杀券聚合模型和 Redis 追踪日志模型。 |

### 4.3 高并发与一致性能力

| 包路径 | 模块职责 |
| --- | --- |
| `org.javaup.cache` | 管理秒杀券 L1 本地缓存及缓存失效事件发布。 |
| `org.javaup.lua` | 封装秒杀资格校验、Redis 原子扣减与失败回滚 Lua 操作。 |
| `org.javaup.kafka.producer` | 发送秒杀下单与缓存失效消息，并处理发送失败回滚。 |
| `org.javaup.kafka.consumer` | 消费异步下单与缓存失效消息，处理超时、失败回滚和消费后任务。 |
| `org.javaup.kafka.redis` | 封装 Redis 库存回滚、重试、失败日志、告警与指标记录。 |
| `org.javaup.delay` | 定义并消费优惠券提醒延迟消息。 |
| `org.javaup.init` | 在应用启动后完成布隆过滤器、缓存清理和秒杀券数据续期等初始化。 |

## 6. 核心调用链

普通业务请求 -> `hmdp-vue3/src/api` -> Axios `/api` -> Vite 开发代理 -> `RefreshTokenInterceptor` -> `LoginInterceptor` -> `controller` -> `service` -> `service.impl` -> `mapper` -> ShardingSphere -> MySQL

登录态校验 -> 请求头 `Authorization` -> `RefreshTokenInterceptor` -> Redis 查询并刷新登录态 -> `UserHolder` -> `LoginInterceptor` 判断是否放行 -> `controller`

秒杀资格获取 -> `VoucherOrderController` -> `RateLimitHandler` 限流 -> `ISeckillAccessTokenService` -> Redis 签发一次性访问令牌 -> 前端携带令牌发起秒杀

秒杀下单 -> 访问令牌校验与消费 -> `VoucherOrderServiceImpl` -> L1/Redis 缓存查询券信息 -> Snowflake 生成订单与追踪 ID -> Lua 原子校验并扣减 Redis 库存 -> Kafka 发送下单消息 -> `SeckillVoucherConsumer` -> 幂等校验 -> 事务扣减 MySQL 库存并写入订单、订单路由与对账日志

秒杀失败分支

`Kafka` 发送失败 / 消息超时 / 消费异常 -> `RedisVoucherData` -> Lua 回滚库存和用户购买标记 -> 重试 -> 记录回滚失败日志、指标与告警

缓存查询 -> L1 本地缓存 -> L2 Redis -> 布隆过滤器 / 空值缓存 / 分布式锁 -> MySQL 回源 -> 回填缓存
